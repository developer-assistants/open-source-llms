Ollama and LM Studio

Fastest path on macOS, Linux, and Windows desktops. Pulls GGUF weights in one command and exposes a local OpenAI-compatible API.

llama.cpp

Low-level C++ engine behind Ollama with direct control over CPU and GPU layer offloading, KV cache quantization, and speculative decoding.

vLLM

Production GPU server with PagedAttention, continuous batching, AWQ/FP8/MXFP4 kernels, and tensor parallelism across multi-GPU nodes.

SGLang

High-throughput serving runtime using RadixAttention prefix caching for multi-turn agent loops, structured JSON outputs, and large MoE clusters.
